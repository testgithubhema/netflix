# StreamFlix

StreamFlix is a Netflix-inspired streaming media front-end built with React and Vite.

## Features

- Cinematic dark theme and hero banner
- Movie and TV show catalog pages
- Search, trending, and recommendation sections
- Watchlist, continue watching, and profile UX
- LocalStorage-based auth and state persistence
- Responsive layout for desktop, tablet, and mobile

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local Vite URL displayed in the terminal.

## Production build

```bash
npm run build
```
